    BLDC的重要参数

    最近在做无刷电机（BLDC）六步换向的仿真和控制，这篇文章讲讲BLDC（直流无刷电机）的重要参数，根据参数的类型我把它们分成电气参数、机械参数、磁链参数、额定/极限参数，以及一些其他对建模有用的参数。（重点：电气参数）

    一、电气参数（重点）

    参数 符号 单位 说明 重要性
    相电阻 \(R_s\) \(\Omega\) 每相定子绕组的直流电阻，决定稳态电流和铜损 ★★★★★
    相电感 \(L_s\) H 每相绕组的自感（对于表贴式BLDC，\(L_d = L_q = L_s\)），决定电流上升/下降速度 ★★★★★
    极对数 \(P\) 无 转子永磁体的极对数（极数/2），决定电角速度与机械角速度的关系：\(\omega_e = P \omega_m\) ★★★★☆
    反电势常数 \(K_e\) V·s/rad 或 V/rpm 单位机械角速度（或转速）产生的相反电势峰值或线有效值。需要明确是线还是相、有效值还是峰值。对于建模，\(K_e = P\psi_f\)（电角速度基值下） ★★★★★
    转矩常数 \(K_t\) Nm/A 单位电流（通常为q轴电流）产生的电磁转矩。理论上有 \(K_t = \frac{3}{2} P \psi_f\) ★★★★★

    注意：厂家常提供线电阻和线电感（UV、UW、VW之间测得的数值）。对于Y型绕组：
    \(R_s = R_{\text{线}} / 2\)， \(L_s = L_{\text{线}} / 2\)。

    二、机械参数

    参数 符号 单位 说明 重要性
    转动惯量 \(J\) kg·m² 转子及负载折算到电机轴的总转动惯量，决定机械时间常数 ★★★★★
    粘滞摩擦系数 \(B\) Nm·s/rad 轴承和风阻等产生的阻尼，通常较小，在简化模型中可忽略 ★★★☆☆
    静摩擦转矩 \(T_{\text{fric}}\) Nm 启动时需要克服的静摩擦力，对低速控制影响较大 ★★★☆☆

    三、磁链参数

    参数 符号 单位 说明 重要性
    永磁体磁链 \(\psi_f\) Wb 或 V·s/rad 转子永磁体在定子相绕组中产生的磁链幅值。它与反电势常数直接相关 ★★★★★
    \(d\)轴电感 \(L_d\) H 对于凸极式BLDC（内嵌永磁体），\(L_d \neq L_q\)，需要分别给出 ★★★★☆
    \(q\)轴电感 \(L_q\) H 同上 ★★★★☆

    对于表贴式BLDC（大多数小型、低成本电机）：\(L_d = L_q = L_s\)。

    四、额定/极限参数

    参数 符号 单位 说明 重要性
    额定电压 \(V_{\text{rated}}\) V 通常为直流母线电压，决定了最大输出能力 ★★★★☆
    额定电流 \(I_{\text{rated}}\) A 长时间安全工作电流，用于设置电流环限幅 ★★★★☆
    峰值电流 \(I_{\text{peak}}\) A 短时允许最大电流（通常为额定2~3倍），决定最大加速转矩 ★★★☆☆
    额定转速 \(n_{\text{rated}}\) rpm 额定工况下的机械转速 ★★★☆☆
    额定转矩 \(T_{\text{rated}}\) Nm 额定输出转矩 ★★★☆☆
    最大允许转速 \(n_{\text{max}}\) rpm 机械极限（离心力、轴承限制） ★★★☆☆

    五、其他对建模有用的参数

    • 霍尔传感器安装角度（120°或60°电角度）——用于方波控制的换相逻辑。
    • 编码器分辨率（脉冲数/转）——用于速度/位置反馈精度。
    • PWM频率——影响电流纹波和控制器设计带宽。

    六、如何根据实测参数快速建立模型（回顾我的数据）

    下面是张老师提供的数据：

    实测项 值 换算后的模型参数
    线电阻 (UV 3.1Ω, UW 3.4Ω, VW 3.4Ω) 平均3.3Ω 相电阻 \(R_s = 1.65\,\Omega\)
    线电感 (UV 3.17mH, UW 3.64mH, VW 3.46mH) 平均3.42mH 相电感 \(L_s = 1.71\,\text{mH}\)
    反电势系数 0.014 Vrms·s/rad 含义需确认 若为线电压有效值/机械角速度，则相反电势峰值/电角速度 \(\psi_f\) 需换算
    转矩常数 0.08 Nm/A 明确 \(K_t = 0.08\) 直接使用
    转子惯量 7.35 g·cm² 换算 \(J = 7.35\times10^{-7}\,\text{kg·m}^2\)
    极数 4 极对数 \(P = 2\)

    有了上述参数，就可以写出完整的传递函数或状态空间模型。

    总结：最重要的五个参数是 \(R_s, L_s, K_t, J, P\)。如果你只能获取少量参数，优先测量或获取这五个。对于更高精度的控制（如弱磁、MTPA），则需要 \(L_d, L_q, \psi_f\) 的准确值。
