## 一、目录与文件操作

| 命令 | 用途 | 示例 |
|------|------|------|
| **`pwd`** | 查看当前所在目录（Print Working Directory） | `pwd` → `/home/swq/ros2_ws` |
| **`ls`** | 列出当前目录内容 | `ls` / `ls -a`（含隐藏文件）/ `ls -l`（详细信息） |
| **`cd 路径`** | 切换目录 | `cd ~/ros2_ws`、`cd ..`（上一级）、`cd ~`（回家目录） |
| **`mkdir -p 路径`** | 创建目录（-p：缺哪层建哪层） | `mkdir -p ~/ros2_ws/src` |
| **`cat 文件`** | 把文件内容打印到屏幕（看配置最常用） | `cat ~/map.yaml` |
| **`rm 文件`** | 删除文件 | `rm old.py` |
| **`rm -rf 目录`** | **递归强制删除**（危险！Linux 无回收站） | `rm -rf build install log` |
| `cp 源 目标` | 复制文件/目录 | `cp a.py ~/backup/a.py` |
| `mv 源 目标` | 移动/重命名 | `mv old.py new.py` |
| `touch 文件` | 创建空文件/更新时间戳 | `touch ~/notes.txt` |

**⚠️ 安全提醒**：`rm -rf` 删了就找不回来。**先 `pwd` 确认位置，再动手**；只删自己确认的目标（build/install/log 这类可再生目录）。

## 二、查看与搜索

| 命令 | 用途 | 示例 |
|------|------|------|
| `grep 关键词 文件` | 在文件里搜关键词 | `grep turtlebot3 ~/map.yaml` |
| `命令 \| grep 关键词` | 过滤命令输出（**高频！**） | `ros2 pkg list \| grep motor_demo` |
| `head 文件` | 看文件开头几行 | `head -20 setup.py` |
| `tail 文件` | 看文件末尾几行（查日志最常用） | `tail -50 log.txt` |
| `wc -l 文件` | 数行数 | `wc -l setup.py` |
| `which 命令` | 查命令装在哪个路径 | `which python3` |
| `find 目录 -name 文件名` | 按名字搜文件 | `find ~/ros2_ws -name "*.py"` |

**管道 `\|` 是最常用的组合**：`A | B` = 把 A 的输出交给 B 处理。例：`ros2 node list | grep pub` = "列出所有节点，只要含 pub 的"。

## 三、安装与软件管理

| 命令 | 用途 | 示例 |
|------|------|------|
| `sudo apt update` | 刷新软件源列表（装包前先跑） | `sudo apt update` |
| `sudo apt install 包名` | 安装软件包 | `sudo apt install ros-humble-gazebo-*` |
| `sudo apt remove 包名` | 卸载软件包 | `sudo apt remove ros-humble-xxx` |
| `apt list --installed` | 列出已安装的包 | `apt list --installed \| wc -l` |
| `apt search 关键词` | 搜索软件源里有没有这个包 | `apt search turtlebot3` |
| `sudo apt autoremove` | 清理不再需要的依赖 | `sudo apt autoremove` |

**几个要点**：
- `sudo` = 用管理员权限执行（装系统级软件必须）。输密码时**屏幕不显示**，正常现象，盲打回车即可
- ROS 包名的规律：`ros-humble-包名`（Humble 版本专用）
- "缺什么装什么"：报错里出现 `Could not find xxx` → `sudo apt install ros-humble-xxx`

## 四、Git 与版本控制

| 命令 | 用途 | 示例 |
|------|------|------|
| `git clone 地址` | 下载仓库到当前目录 | `git clone -b humble https://github.com/...git` |
| `git clone -b 分支 地址` | 下载指定分支 | `git clone -b humble https://github.com/ROBOTIS-GIT/turtlebot3.git` |
| `git status` | 查看工作区状态（改了哪些文件） | `git status` |
| `git log` | 查看提交历史 | `git log --oneline` |
| `git diff` | 查看改动内容 | `git diff` |
| `git add 文件` | 把改动加入暂存区 | `git add .`（全部） |
| `git commit -m "说明"` | 提交一次版本 | `git commit -m "add publisher"` |
| `git config --global 键 值` | 设置全局配置 | `git config --global http.version HTTP/1.1` |
| `ssh-keygen -t ed25519 -C "邮箱"` | 生成 SSH 密钥（配 GitHub 用） | 一路回车即可 |
| `ssh -T git@github.com` | 测试 SSH 是否连上 GitHub | 显示 `Hi xxx!` 即成功 |

**GitHub 国内访问不稳定时的对策**（按顺序试）：
1. 重试：`git clone 原地址`
2. 降协议：`git config --global http.version HTTP/1.1` 后重试
3. 换镜像：`https://ghproxy.com/https://github.com/...`

## 五、权限与用户

| 命令 | 用途 | 示例 |
|------|------|------|
| `sudo 命令` | 以管理员权限执行 | `sudo apt install xx` |
| `chmod +x 文件` | 给文件加执行权限 | `chmod +x script.sh` |
| `chmod 权限数字 文件` | 精确设置权限 | `chmod 755 script.sh` |
| `whoami` | 查看当前用户名 | `whoami` → `swq` |
| `passwd` | 修改当前用户密码 | `passwd` |

**权限数字简记**：4=读，2=写，1=执行，相加得数。`755` = 所有者全权限，其他人读+执行。

## 六、进程管理

| 命令 | 用途 | 示例 |
|------|------|------|
| `Ctrl+C` | **中断当前前台程序**（ROS 里停止节点最常用） | 跑着节点时按它 |
| `ps aux` | 列出所有进程 | `ps aux` |
| `ps aux \| grep 名字` | 查某个进程在不在（**高频**） | `ps aux \| grep gzserver` |
| `pkill -f 名字` | 按名字杀进程（-f 按完整命令行匹配） | `pkill -f gzserver` |
| `kill -9 PID` | 强杀指定进程 | `kill -9 4534` |
| `top` / `htop` | 实时看 CPU/内存占用 | `htop`（更直观） |

**ROS 场景**：节点卡住/占用终端 → 先 `Ctrl+C`；多个残留进程 → `pkill -f 进程名`。

## 七、环境变量与 shell 配置

| 命令 | 用途 | 示例 |
|------|------|------|
| `export 变量=值` | 设置环境变量（**只对当前终端有效**） | `export TURTLEBOT3_MODEL=burger` |
| `unset 变量` | 取消环境变量 | `unset MESA_D3D12_DEFAULT_ADAPTER_NAME` |
| `echo $变量` | 查看变量值 | `echo $ROS_DISTRO` → `humble` |
| `source 文件` | 让配置文件**立即生效** | `source install/setup.bash` |
| `echo '内容' >> 文件` | 把内容**追加**到文件末尾（写 .bashrc 常用） | `echo 'export TURTLEBOT3_MODEL=burger' >> ~/.bashrc` |
| `vim ~/.bashrc` | 直接编辑配置文件 | 或 `nano ~/.bashrc`（更简单） |
| `alias 别名='命令'` | 给长命令起短名字 | `alias rb='cd ~/ros2_ws && colcon build && source install/setup.bash'` |

**关键认知（ROS 学习者最容易懵的点）**：
- `export` 设的变量**只活在当前终端**，关掉就没了 → 想永久生效就写进 `~/.bashrc`
- `source ~/.bashrc` 让新配置**立刻生效**（否则要重开终端）
- `.bashrc` 是"终端启动自启动脚本"——里面写的 export/source/alias 每个新终端自动执行

**ROS 常用配置合集（写进 .bashrc 一劳永逸）**：

```bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
echo "source ~/ros2_ws/install/setup.bash" >> ~/.bashrc
echo "source ~/turtlebot3_ws/install/setup.bash" >> ~/.bashrc
echo 'export TURTLEBOT3_MODEL=burger' >> ~/.bashrc
echo 'export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:/opt/ros/humble/share/turtlebot3_gazebo/models' >> ~/.bashrc
source ~/.bashrc
```

## 八、系统资源查看

| 命令 | 用途 | 示例 |
|------|------|------|
| `free -h` | 查看内存使用（-h 人性化单位） | 看 Mem 行的 available |
| `df -h` | 查看磁盘占用 | `df -h /`（根分区） |
| `du -sh 目录` | 查看目录占多大 | `du -sh ~/ros2_ws` |
| `uname -a` | 查看系统信息 | 内核版本等 |

**场景**：Gazebo/RViz 卡死时先查 `free -h`——内存不足是最常见原因。

## 九、网络与下载

| 命令 | 用途 | 示例 |
|------|------|------|
| `wget 网址` | 下载文件 | `wget http://fishros.com/install -O fishros && bash fishros` |
| `curl 网址` | 下载/请求（功能更强） | `curl -O 文件地址` |
| `ping 域名` | 测试网络连通 | `ping baidu.com` |
| `ssh 用户@主机` | 远程登录 | `ssh swq@192.168.1.10` |

**WSL 专属**：
- `explorer.exe 路径`：用 Windows 资源管理器打开 WSL 文件（看地图图片常用）→ `explorer.exe ~/map.pgm`
- `wsl --update` / `wsl --shutdown`：在 Windows PowerShell 里更新/重启 WSL

## 十、文件编辑

| 方式 | 说明 | 适合 |
|------|------|------|
| `nano 文件` | 最简单，底部有按键提示 | 新手改小配置 |
| `vim 文件` | 功能强，需学（按 i 编辑，Esc 退出，:wq 保存退出） | 常用后效率高 |
| **VS Code 远程** | Windows 里直接编辑 WSL 文件，图形界面 | **ROS 开发首选** |

**VS Code 打开 WSL 文件**：VS Code 装 "WSL" 插件 → `code ~/ros2_ws`（在 WSL 终端里敲）→ 图形界面编辑 + 文件树，最舒服。

## 十二、命令组合技巧（管道/重定向/别名）

| 符号 | 意思 | 示例 |
|------|------|------|
| `A \| B` | **管道**：A 的输出给 B 当输入 | `ros2 topic list \| grep scan` |
| `> 文件` | **重定向**：输出覆盖写入文件 | `echo hello > a.txt` |
| `>> 文件` | **追加**：输出追加到文件末尾 | `echo xxx >> ~/.bashrc` |
| `A && B` | A 成功才执行 B（串联） | `wget ... && bash fishros` |
| `A; B` | 不管 A 成不成都执行 B | `pkill gzserver; pkill gazebo` |
| `\` 行尾 | 换行继续写（长命令折行） | 见 apt install 多包写法 |
| `*` | 通配符（匹配任意） | `ros-humble-gazebo-*`（所有 gazebo 开头的包） |
| `~` | 当前用户家目录 | `~/.bashrc` = `/home/swq/.bashrc` |
| `$变量` | 取变量的值 | `echo $ROS_DISTRO` |

## 十三、ROS2 高频命令（回顾）

```bash
# 工作空间 / 包
colcon build                          # 编译（必须在工作空间根目录）
colcon build --symlink-install        # 编译 + 源码快捷方式（开发期推荐）
source install/setup.bash             # 让终端认识编译产物
ros2 pkg list | grep 包名             # 查包是否存在
ros2 pkg create --build-type ament_python 包名   # 建 Python 功能包

# 节点 / 话题 / 服务 / 参数
ros2 node list                        # 运行中的节点
ros2 run 包名 入口名                  # 运行节点
ros2 topic list / echo 话题 / info 话题
ros2 service list / call 服务名 类型 "{参数}"
ros2 param list / get / set 节点名 参数名 值

# launch
ros2 launch 包名 文件名.launch.py     # 一键启动多个节点
```
